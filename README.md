# Chen Chen — Personal Robotics Website

This repository is a customized personal website scaffold built on the
[Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll framework.

It is organized around:

- **Projects** — physical robotic systems and engineering work
- **Publications**
- **Blog** — Markdown-based technical writing
- **Photos** — project, travel, and visual notes

The site uses Academic Pages as a pinned `remote_theme`, so this repository stays lightweight while retaining the Academic Pages layouts and styling.

## Quick deployment

1. Create a public GitHub repository named `fjiwrogno.github.io`.
2. Upload the contents of this folder to that repository.
3. Push to `master` or `main`.
4. In **Settings → Pages**, select **GitHub Actions** as the source if needed.
5. Wait for the `Build and deploy Jekyll site` workflow to finish.
6. Visit `https://fjiwrogno.github.io`.

If you publish from a different GitHub account, edit `url`, `repository`, and `author.github` in `_config.yml`.

See `SITE_EDITING_GUIDE.md` for the files you will normally edit.
